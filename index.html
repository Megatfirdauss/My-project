Keperluan OTP bomber

  • Nombor E.164, negara mesti padan dengan domain platform.
  • APK tak perlu CORS proxy. Proxy residensial Malaysia hanya untuk elak 429.
  • User-Agent mobile wajib — dari APK sudah betul, dari desktop banyak gagal.
  • Jeda 4–9 saat; OTP kedua dalam 60 saat biasanya diabaikan.
  • Tiada API key. Platform bertanda rendah perlukan token — guna backend Node.

Keperluan WhatsApp crash

  • Kos render, bukan saiz. Zalgo, emoji ZWJ dan bidi paling berat.
  • vCard bomb: ribuan baris TEL dalam satu kad.
  • Berkesan pada Android RAM rendah; flagship cuma lewat 2–5 saat.
  • Automasi penuh: Baileys (Node). Had WhatsApp ~15–20 mesej/minit.

Nota

  • Platform tukar skema tanpa notis. Kalau satu gagal berulang, tambah header di backend.
  • TNG eWallet, AirAsia, Booking perlukan signature — backend sahaja.
